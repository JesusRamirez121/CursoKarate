# DEMO PETS service

## Installation

```
npm install
```


## Run the project

El servicio escucha en el puerto 3001 y guarda los datos en `pets.json` (se modifica al crear, editar o borrar mascotas; restaurar con `git checkout -- pets-demo/pets.json`).

```
node app.js
```

## Service URL

```
http://localhost:3001/
```

## Swagger URL

```
http://localhost:3001/api-docs
```
